# Non-Messaging protocol telemetry matrix

This is the measurement inventory for PROTO-A/PROTO-B in the
[implementation spec](../archive/plans/ROADMAP_IMPLEMENTATION_SPEC_2026-10-28.md#proto-b--controlled-endpoint-qualification),
under the [diagnostics](../PROTOCOL_DIAGNOSTICS.md) and
[support](../PROTOCOL_SUPPORT.md) contracts. It records the exact local cohorts
verified by the [Java admission and protocol review](../archive/qa-reviews/TELEMETRY_AND_PROTOCOL_SLICES_2026-10.md#roadmap-java-encoding-admission-2026-10-19), the [Java representation review](../archive/qa-reviews/TELEMETRY_AND_PROTOCOL_SLICES_2026-10.md#roadmap-java-representations-2026-10-20), the [controlled-endpoint review](../archive/qa-reviews/TELEMETRY_AND_PROTOCOL_SLICES_2026-10.md#roadmap-controlled-endpoints-2026-10-20) and the [HTTP byte evidence review](../archive/qa-reviews/ANALYTICS_SLICES_2026-10.md#roadmap-native-byte-evidence-2026-10-22).
It does not close the protocol roadmap row. Messaging and CloudTest outcome
parity remain excluded.

`TestProtocolTelemetryMatrixCitesRealTests` (`docs/qa/protocol_matrix_test.go`) checks two things:
- every relative link here resolves to an existing file;
- every test cited in a code span is declared, in a test file its table row links (or, outside the tables, in a test file of the repository).

## Local measurement and failure inventory

All endpoint fixtures below run on one darwin/arm64 host with pinned Go modules.
They use synthetic loopback endpoints; no customer capture is replayed. Exact
commands, runtime/module versions, source hashes, passing test names and failed
before-fix evidence are retained in the review. The tests establish functional
semantics for those fixtures, not resource overhead or deployed performance.

These are loopback functional fixtures. They are not transport-byte, reference-host or deployed qualification.

| Measurement | Independent fixture | Qualified scope and limits |
| --- | --- | --- |
| HTTP body bytes on the wire | [Adapter fixture](../../pkg/protocol/http/byte_evidence_test.go), `TestHTTPByteEvidenceMeasuresWireBodies`; merge unit test `TestMetaRefreshKeepsThePagesByteEvidence` | **Exercised.** A live plain-HTTP loopback server checks each count: a gzip body counts its compressed length, a fresh cache hit and a response served after a 304 receive nothing, a POST body counts as sent, a refused dial sends nothing, and an action refused before dispatch is `none`. A unit test merges a meta-refresh page into its follow-up. **Defined, not exercised here.** Headers, framing and TLS are not counted, and neither are redirects' re-sent bodies, retries' earlier attempts, embedded-resource bytes or live meta-refresh bytes. |
