RefKey case normalization and cross-replica lookup use durable state. Existing protected import/approval receipt semantics, project boundaries, secret-reference mutation fences and publication visibility remain enforced. Strong ETags apply only to the authoring representation; enriched responses carry the coherent final projection and revision without an enriched-body ETag.
