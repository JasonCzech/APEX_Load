# REC-C1: Repeatable 3-Rep Integrated Local Fault Qualification Review (2026-10-28)

## Scope

This review record documents the repeatable 3-repetition local fault qualification harness (`REC-C` / `REC-C1`) defined in [ROADMAP_IMPLEMENTATION_SPEC.md](../../../archive/plans/ROADMAP_IMPLEMENTATION_SPEC_2026-10-28.md) and [NODE_FAILURE_READINESS_PLAN.md](../../../NODE_FAILURE_READINESS_PLAN.md) (Package 8: Integrated Fault Qualification, Soak, and Release Gates).

- **Qualification Harness**: [`TestRECCIntegratedLocalFaultQualification3Rep`](../../../../pkg/api/rec_c_local_fault_qualification_test.go)
- **Real Generator Fleet Execution**: Every participating generator (`gen-0`, `gen-a`, `gen-b`, `gen-c`, `gen-d`, `gen-e`) runs a real in-process `generatorrpc.Service` with `WithExecution()` enabled. Outbound VUser HTTP requests carry `X-Apexload-Fault-Generation` stamped strictly from the generation accepted by each generator's real gRPC control plane (`ClaimExecutionEpoch`, `ClaimExecutionEpochWithAdoptions`, `ClaimRunSupervision`, `AssignWork`).
- **Independent Target Contract**: In-process authenticated HTTP target implementing the exact `/healthz`, `/load`, and `/snapshot` Bearer-token and per-generation accounting contract of [`cmd/apexfault-target/main.go`](../../../../cmd/apexfault-target/main.go) and [`cmd/apexfault-target/observe.go`](../../../../cmd/apexfault-target/observe.go).
- **Retained Evidence & Controller Capacity Reconciliation**: Each repetition reads retained generator/controller archive artifacts (`manifest.json` and `transactions.jsonl`) via `GetArchiveArtifact` and verifies `retained_evidence_transactions == target_total_requests == reconciled_generation_sum`, and drives the controller's own `reconcilePodCapacity` loop to release all pod capacity reservations (`active_reservations_after_terminal == 0`).
- **Raw Machine-Readable Evidence**: `docs/qa/reviews/roadmap-rec-c-local-faults-2026-10-28/summary.json` (generated by setting `APEXLOAD_REC_C_EVIDENCE_DIR`).
- **Execution Matrix**: 7 fault scenarios × 3 fresh repetitions = **21 independent qualification runs** (all 21 passed with `-race` enabled).
- **External Boundary Note**: This qualification closes the repeatable 3-repetition local integrated fault gate (`REC-C`). Multi-node cloud cluster soak and live cloud node-drain qualification (`REC-D`) remain an explicit external gate requiring provisioned cloud cluster infrastructure.
