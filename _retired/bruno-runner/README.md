# Retired bruno-runner

This is a cold source archive of feature-owned Bruno Runner implementation files,
excluded from product builds and ordinary tests. [`manifest.json`](manifest.json)
records the original repository paths and SHA-256 digests of the retained files
from baseline revision `0a480cee9d80efd68c984e2cbc1627e25443b2fd`; shared
mixed-concern integration points at retirement time remain retrievable from git
history at that commit.

Restore by deliberately reintegrating the implementation into the current architecture,
updating dependencies, contracts, deployment settings, security policy and tests.
Archived code is not a maintained optional build. Stored application data, artifacts,
volumes and encryption keys are preserved separately in the active product.
